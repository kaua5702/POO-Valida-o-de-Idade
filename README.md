# Verificador de Idade

## 📌 Descrição
Este projeto em Java implementa um programa simples para verificar e apresentar a idade de uma pessoa.  
A classe `Pessoa` garante que a idade não seja negativa e fornece um método para exibir a idade atual.  
A classe `App` contém o método `main`, responsável por instanciar objetos e demonstrar o funcionamento.

## 🚀 Tecnologias
- Linguagem: **Java**
- Paradigma: **Orientação a Objetos**
